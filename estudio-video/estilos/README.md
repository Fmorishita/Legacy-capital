# Estilos aprendidos de referencias

Cada archivo `<nombre>.md` es el estilo medido de un video de referencia que subiste a la Sala de Revisión
(`herramientas/referencia.py` mide; Claude completa mirando las hojas de contacto). Misma estructura que `../estilo.md`.

Para usarlo en un video nuevo, dilo en el brief: `estilo: estilos/<nombre>.md`. Sin indicación se usa `../estilo.md`.
Del video de referencia solo se copian parámetros de estilo, nunca contenido (música, clips, textos, logos).
